> WHAT IS THEHARVESTER

theHarvester is an OSINT tool by Christian Martorella. It scrapes emails, subdomains, and IPs from public sources: search engines (Google, Bing, Baidu), certificate transparency logs (crt.sh), passive DNS, shodan, LinkedIn, and more.

Running theHarvester -d target.com -b all -f results produces results.json — a flat array of raw intel: emails[], hosts[], ips[] aggregated from all sources, no deduplication, no formatting.

> WHY THIS SCRIPT

The raw theHarvester JSON has problems:

  • No deduplication (same email from 3 sources appears 3 times)
  • IPs mixed into the hosts[] array
  • No counts — you can't quickly see "how many unique emails?"
  • No structured output for downstream tools

What this script adds:

  • Deduplicates and sorts emails, hosts, IPs
  • Separates IP addresses from hostnames
  • Counts: email_count, host_count, ip_count, source_count
  • SQLite cache — repeat imports instant (24h TTL)
  • Structured JSON for piping to httprobe, subfinder, etc.
> HOW IT WORKS
python3 harvester-importer.py -d target.com -f results.json
▼
PARSE + NORMALIZE dedup · split IPs from hosts · count
▼
SQLITE CACHE (cache.db) fresh (<24h)? serve instantly stale? re-read input file
▼
NORMALIZED INTEL email_count · host_count · ip_count · source_count
> USAGE
# basic import — results printed + cached 
python3 harvester-importer.py -d target.com -f results.json
# save normalized JSON to file 
python3 harvester-importer.py -d target.com -f results.json -o normalized.json
# specify which sources you used (shows on Intel Board) 
python3 harvester-importer.py -d target.com -f results.json --sources "crtsh,baidu,bing"
# submit to community Intel Board 
python3 harvester-importer.py -d target.com -f results.json --submit
